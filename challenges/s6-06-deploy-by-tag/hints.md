Tags first, and make them mean something. `git tag -a v-lab-1 -m 'baseline'` on the current commit, then change something the running page shows — a heading, a version string — commit it, and `git tag -a v-lab-2 -m 'visible change'`. An annotated tag (`-a`) carries a message and a date; a lightweight one is just a pointer, and six months later you will want the message.
Check the tag exists before you touch anything: `git -C "$dir" rev-parse -q --verify "refs/tags/${tag}"`. Spelling `refs/tags/` out matters — a bare name also matches branches, so a typo that happens to be a branch name will deploy the branch and look like it worked.
Check out detached, on purpose: `git checkout --detach "refs/tags/${tag}"`. Checking out a tag by name already detaches and warns about it; `--detach` says you meant it. What you must not do is create a branch at the tag, because then the next `git pull` on that branch silently moves what you thought was a fixed version.
`git pull` is the thing this challenge exists to replace. It fetches and merges in one step, and what you get depends on when you run it. If you need the tags themselves, `git fetch --tags` is the fetch without the merge — the fetch is fine, the merge is what makes the deployment unnameable.
Record the deployment outside the checkout — append the tag and a timestamp to a file under `/var/lib`. `git describe` answers "what is this tree at", which changes the moment anyone runs a git command in that directory; the record answers "what did we deploy, and when", which is the question you have during an incident.
Verify inside the script, before it exits 0: curl the app and fail loudly if it does not answer. A deploy script that reports success on a broken deployment is worse than one that does nothing, because the next person reads the success line and looks somewhere else.
Make the rollback the same command with a different argument. If rolling back needs a different procedure from deploying, it is a procedure you will be improvising at the worst possible time — and the entire value of this pattern is that the rollback is already tested, because it is the thing you have done four times today.
